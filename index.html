About this collection & privacy

This collection brings together 14 Coded Female games with fictional learning examples. No competitor scenarios, screenshots or artwork were copied.

No sign-up or live AI service is needed. Bug Bash saves your best score in this browser using local storage. Other game progress resets on reload. Some earlier games request fonts from Google Fonts; the six newest games serve fonts locally. GitHub Pages handles ordinary hosting requests.

Each game has its own format and supporting guidance. Bug Bash includes timed arcade play and a practice mode. These exercises are introductions, not certifications or full professional assessments.
