YOUR TURN / MAKE A WORKING PROJECT

Change the code. See what grows.

Edit the short sections below. The rest of each file is supplied. Try changing increment = 1 to increment = 2, then click the counter in your preview.

Updates happen after you pause typing. A valid update restarts the preview counter. Invalid edits stay in the editor while the last working preview remains available.

Change the words between the tags. Keep one <h1> and one <p>, including their closing tags. Use plain text inside them.

Try #f1a4d5 for berry or #a6e5bd for forest. You can use any three- or six-digit hex colour. Keep the braces, colon and semicolon.

Use quoted text for greeting and a whole number from 1 to 10 for increment. Keep both names and semicolons. Single or double quotes work.

What can I edit here?

This guided editor supports the two HTML elements shown, one CSS colour variable and the two JavaScript constants. It helps you practise a small change with useful feedback. It does not run arbitrary code.

The download includes these edits inside complete HTML, CSS and JavaScript files. After extracting the project, you can explore the whole code in a text editor.

Tab moves to the next control. In the file tabs, use Left and Right arrows to switch sections. Your edits stay in this tab only. Download before closing or refreshing.

Take your project with you.

  • index.html: your heading and paragraph, plus the supplied controls.
  • style.css: your accent and the supplied layout.
  • script.js: your greeting and increment, plus the supplied event handlers.
  • README.txt: how to open it and one next challenge.
