# First Code Playground

A fun first website built with plain HTML, CSS and JavaScript. No installation or build step needed.

## Try it on your computer

Keep the three code files in the same folder. Double-click `index.html` to open it in your browser. Edit a file in a text editor, save it, then refresh the browser to see your changes.

## What each file does

| File | Purpose |
| --- | --- |
| `index.html` | The page content and structure |
| `style.css` | Colours, spacing and mobile layout |
| `script.js` | Greeting, colour buttons, counter and quiz |

The code includes comments to help you find your way around. Changes made using the page controls reset when you reload. The greeting stays in your browser; it is not sent anywhere.

## Put it on GitHub

1. Create a new public repository called `first-code-playground`. A repository is a folder for your project on GitHub.
2. Choose **Add file → Upload files**. Upload `index.html`, `style.css`, `script.js` and this README directly into the repository, without an enclosing folder. Commit the files, which saves this version of your project.
3. Open **Settings → Pages**. Under **Source**, choose **Deploy from a branch**.
4. Choose **main** and **/(root)**, then select **Save**.
5. When deployment finishes, GitHub’s Pages settings will show your website link. For this repository name, it will normally be `https://YOUR-USERNAME.github.io/first-code-playground/`.

Official instructions: [Configure a GitHub Pages publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Three small challenges

1. Change the main heading in `index.html`.
2. Change the default `--accent` colour at the start of `style.css`.
3. Change `count += 1` to `count += 2` in `script.js`.

Once you’ve tried those, add a fourth colour button. You’ll need a button in HTML, a swatch style in CSS and a matching palette in JavaScript.
